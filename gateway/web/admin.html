      Utiliser l'IA sur le web

      Un compte gratuit sur lezard-ia.fr retient l'adresse de ce PC et une clé créée pour le web : ensuite, identifiant et mot de passe suffisent, depuis n'importe quel appareil. La clé est chiffrée avec votre mot de passe, dans votre navigateur.

      D'abord : la double authentification de ce PC. Scannez ce QR code avec une application d'authentification (Google Authenticator, Microsoft Authenticator, Aegis…), puis saisissez le code à 6 chiffres. Depuis Internet, ce code sera toujours demandé en plus du mot de passe du compte : il est vérifié par ce PC seulement.

      Sans appareil photo, saisissez cette clé :

      Codes de secours : notez-les. Chacun remplace une fois le code du téléphone, si vous le perdez.

      Depuis n'importe où : lezard-ia.fr, « Utiliser l'IA sur le web », avec votre clé web .

      Code de licence (facultatif)

      Rien à faire ici sans code : tout le logiciel est inclus. Si vous avez reçu un code de licence, collez-le pour l'activer sur ce PC.

      Il commence par LZ1. et il est vérifié sur ce PC.

            Mode économie …

            Les IA locales consomment le moins possible de ressources de ce PC, pour tout le monde : une requête à la fois, modèles légers, réponses plus courtes, carte graphique et processeur bridés, mémoire vidéo libérée vite, Ollama en priorité basse, recherche dans les documents mise à jour plus tard.
